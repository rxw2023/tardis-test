## 时空舱处理（本格核心）
**不调用 `drawCapsule`**。舱体由**代码本身一笔一笔画出来**：
- 在代码区右侧 `x 660..960, y 130..700` 开一个**预览面板**（一个 1.5 单位边框 #30363d 的圆角矩形 + 左上角一行小字 `preview`）。面板内是透明的编辑区底色。
- 代码区写的是一段真实的 SVG 源码（自撰，例如）：
  ```
  <svg viewBox="0 0 200 220">
    <rect class="body" x="20" y="60" width="160" height="150"/>
    <polygon class="eave" points="10,60 60,38 140,38 190,60"/>
    <circle class="lamp" cx="100" cy="26" r="16"/>
    <rect class="win" x="36" y="82" width="42" height="30"/>
    ... （6 个窗）
    <circle class="dial" cx="140" cy="180" r="14"/>
    <animateTransform .../>     ← 最后一行，让漩涡转起来
  </svg>
  ```
- **联动规则**：每写出一行代码，预览面板里对应的那一个图形元素就在 0.25 秒内**描边淡入**（先画描边、再填色）。行号 `i` 与预览元素一一对应（用一个 `{ line: i, draw: fn }` 的数组描述）。
- 舱体的 SVG 用色：body #1f8a94、eave #14606a、trim #c9973f、lamp #ffd97a、win #0d3940 —— 与 `DEFAULT_CAPSULE` 一致（写死在文件里，不要 import capsule 的具体值，避免耦合）。
- **最后一行 `<animateTransform>` 写完**：预览里灯笼位置的漩涡**开始旋转**（`swirlAngle(t)`），同时整个预览面板的边框亮一次（#7ee787，0.4 秒衰减）。
