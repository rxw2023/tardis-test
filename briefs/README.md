# 美术简报规格（阶段 3 派子代理用）

每个版块一份 `briefs/NN-<slug>.md`，子代理只读这一份 + `src/kit`、`src/beat`，不得改动其他人的文件。

## 必填字段

```
# NN 版块名（中文 / English / 年代）
- 画风锚点：一句话说清"像什么"，以及不超过 3 个具体参照（必须是公有领域作品）
- 构图：主体位置、视平线、天/地比例、留白策略（1000×1000 单位空间）
- 笔法：笔触粗细范围、边缘处理、是否飞白/晕染/抖动/像素化
- 调色：底色 / 主墨色 / 点缀色（精确 hex），明度关系
- 时空舱处理：本版块里舱体以什么形态出现（同一骨架姿势，画法随风格变形）
- 梗（第 2 小节）：一句笑点 + 视觉呈现方式（必须能在一个镜头里看懂）
- 强拍动作：每小节第 1、3、5 拍的可见变化（过框在第 6 秒）
- 禁止项：不得复刻的元素（具体到 logo / 角色 / 界面）
```

## 技术契约

```js
export function render(g, meta, local) {}           // 1000×1000 单位空间，画地面以上部分
export function drawVehicle(g, { x, y, local, t }) {} // 可选：覆盖舱体画法
```

1. `local` 是本版块内 0..6 秒；全局时间只有需要跨版块连续时（如漩涡相位）才用 `t`。
2. 不画公路（`drawRoadUnit` 由主调度画），不画画框/标题卡/字幕。
3. 不使用外部图片、字体文件、音频；只用 `g.createGraphics` 程序化生成纹理，且必须缓存（模块级变量），不能每帧重建。
4. 随机数一律用 `mulberry32(固定种子)`，禁止 `Math.random()`，否则逐帧渲染会闪烁。
5. 每帧必须可重入：不能依赖上一帧状态。
6. 交稿时附一张 `frames/<slug>/` 的 6 帧接触表（local = 0.5 / 2.2 / 3.2 / 4.2 / 5.2 / 5.9）。
