# 18 蒸汽波（Vaporwave / 2010s）

- **index** 17 ｜ 全片时间窗 107.0–113.0s ｜ 文件 `src/scenes/s18-vaporwave.js`
- **画风锚点**：蒸汽波的通用视觉语法——粉紫青渐变、透视网格地面、低多边形棕榈树、古典大理石胸像、横条纹落日、CRT 扫描线与色差。全部自绘，不使用任何真实专辑封面、品牌或字体形象。

## 构图
- 天空 `y 0..470`：从顶部深紫（#2a1440）向下过渡到品红（#ff71ce）再到橙粉（#ff9a3c）的竖直渐变。
- 落日：圆心 `(500, 420)` 半径 `180`，粉黄渐变（#ff9a3c → #ff71ce），被 6 道**横向黑色条纹**切开（条纹高度从下往上递减：18/14/11/8/6/4）。
- 地平线：`y 470`，一道亮青色（#05ffa1）的水平发光线。
- 网格地面 `y 470..1000`：透视网格向地平线收束——
  - 纵向线：从消失点 `(500, 470)` 向下发散到底边，共 17 条，
  - 横向线：按透视间距排布（`y = 470 + 530 * (i/n)^2.4`），并**随时间向前滚动**（`i` 偏移 `local * 0.35`，到底后回卷），
  - 线色 #01cdfe（青）+ 发光（3 层递减 alpha）。
- 棕榈树：左右各 3 棵（低多边形：一根折线树干 + 5~6 片三角形叶），剪影近黑紫（#1a0a2a），带青色边缘光。
- 前景左下 `x 130..330, y 560..860`：一尊**古典大理石胸像**的几何化剪影（侧脸轮廓：额头-鼻-唇-颏的一条折线 + 颈部与肩部的块面），米白（#e8dcd0）+ 粉青的环境反光，站在地面上**旁观**悬浮的舱体。
- **公路**会盖在 `y 770..940` —— 这一带的网格被公路覆盖，把公路理解成"网格中央的一条发光的路带"，在网格之上再叠一层青色的路面高光让它融入。

## 笔法
- 渐变一律用 `createLinearGradient` + `ctx.fillRect`（不要 p5 形状）。
- **发光**：3 层递减 alpha 的同形描边（不要用 `ctx.filter`）。
- **色差（RGB 分离）**：把网格与落日再画两遍，分别用红（#ff2a6d，alpha 0.28）与青（#05ffa1，alpha 0.28），各自水平偏移 ±2.5 单位 —— 用 `g.blendMode(g.SCREEN)` 叠加后立刻还原 `g.blendMode(g.BLEND)`。
- **CRT 扫描线**：每 3 单位一条横线（alpha 0.055），铺满全幅；再叠一层极慢向下滚动的亮带（高 40，alpha 0.04，周期 4 秒）。
- 半透明与渐变都允许，但**不要做柔化模糊**（蒸汽波是硬的）。

## 时空舱处理
用 `drawVehicle` 覆盖：
- 舱体**悬浮在网格上方**：`y = 620 + hoverY(local) * 1.8`，尺寸 0.86。
- 保留青瓷+黄铜本体色，但加上**粉青的环境反光**：左半边叠一层品红（alpha 0.16），右半边叠一层青（alpha 0.16），底部叠一层来自网格的青色反光（alpha 0.2）。
- **拖影（残影）**：在舱体当前位置后方（x - 26 / -52 / -78）画三个半透明副本（alpha 0.22/0.14/0.08），读作"录像带拖影"。
- 舱体在网格上的**投影**：一个被拉长的粉色椭圆（alpha 0.25），随悬浮高度缩放。

## 梗（第 2 小节）：磁带跳针
`local 2.00 ~ 3.00` 期间，画面**卡住并循环半拍**：
```js
let te = local;                                  // 用于动画的"有效时间"
if (local >= 2.0 && local < 3.0) te = 2.0 + ((local - 2.0) % 0.25);
```
所有随时间的动画（网格滚动、棕榈叶摆、扫描亮带、舱体拖影、落日条纹）都用 `te` 而不是 `local`（**舱体的 x 位移除外** —— 位移仍用 `local`，这样"画面在卡，但盒子还在往前走"，笑点才成立）。
- 跳针期间额外叠一层**VHS 噪点带**：一条高 60 的水平噪点带（固定种子 + 按 `Math.floor(local*12)` 换种子，看起来在闪）从画面中部缓慢下移；同时画面整体水平位移 ±6 单位（12fps 阶跃）。
- `local 3.00` 的强拍上"接回正常播放"：噪点带瞬间消失，画面亮度闪一下（+10%，0.15 秒衰减）。

## 强拍动作
- 第 1 拍：地平线的青色发光线闪一下（亮度 +80%，0.2 秒衰减）。
- 第 3 拍：胸像的面颊反光扫过一次（一道斜向的亮带，0.3 秒）。
- 第 5 拍：扫描亮带到达底部（周期 4 秒，与拍错开一点让它不呆板）。
- 过框：全幅色差偏移量加倍（±5 单位）再收回。
