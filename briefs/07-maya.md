# 07 玛雅抄本（Maya Codex / 约1200）

- **index** 6 ｜ 全片时间窗 41.0–47.0s ｜ 文件 `src/scenes/s07-maya.js`
- **画风锚点**：玛雅树皮纸折页抄本的视觉体系——赭黄树皮纸底、黑红双色轮廓、扁平色块、方形字格（glyph block）、页边红色框线、折页中缝。**只取这一公有领域品类**，不描摹任何具体抄本页。

## 构图
- 整幅是一张**摊开的折页**：中央一道竖直折痕（x 500，宽度 26 的暗带 + 两侧各一道亮边），把画面分成左右两页。
- 外框：距边缘 40 单位一圈**红色粗框线**（weight 5，#b03a2e），框内再有一道细黑线。
- 左页 `x 40..487`：上半部是主画面格（一个正方形字格里套着舱体的简化符号），下半部坐着一个侧身执笔的抄写员（戴高羽饰头饰、耳饰、玉串珠）。
- 右页 `x 513..960`：上半部是**第二格画面**（一个行进中的"历法神"抽象形象，背着一个包裹，手里拄杖——自创，不复制真实神祇造型），下半部是**点横数字栏**（见梗）。
- 树皮纸底：`paper(g, { base:[201,143,78], fiber: 2.2, mottle: 0.5 })` —— 纤维要粗、要横竖交织（树皮纸的质感）。

## 笔法
- 轮廓线：黑色（#2a1a10）为主，重要轮廓用红色（#b03a2e），weight 2.5~4.5，端点方，转折略方（抄本是"画框填色"，不是运笔）。
- 填色：完全平涂 + 少量"填出界"的故意错位（用固定种子，约 6 处），读作手抄。
- 装饰：字格内部填小圆点、小短线、螺旋（自创符号）。
- 全幅最后叠一层树皮纸的横向粗纤维与几处虫蛀小孔（固定种子，4~6 个不规则小洞，露出下面更暗的一层）。

## 调色
```
树皮纸 #c98f4e   黑 #2a1a10   玛雅红 #b03a2e   玛雅蓝 #2b6a7a   黄 #e0b040   白 #f0e6d2
```
玛雅蓝只用于头饰羽、水、边框点缀；黄用于神祇与器物。

## 时空舱处理
用 `drawVehicle` 覆盖：
- 舱体被画成**一个巨大的方形字格（glyph block）里的主符号**：格子 240×240，圆角，黑框 + 红细内框，框内是舱体的**极度简化符号**——一个方形 + 3×2 六个小方格（窗）+ 顶上一个圆点（灯笼）+ 底部四道短横（喷口）。
- 格子随舱体 x 移动，但**移动是量化到 8fps 的阶跃**（抄本翻页感），每个阶跃时刻格子轻微旋转 2 度再回正。
- 驾驶员：字格里的小方格中，中间那个格子里有一个侧脸小人（黑线剪影）。

## 梗（第 2 小节）
右页下半部是一栏**玛雅点横数字**（点 = 1，横杠 = 5，贝壳形 = 0，这是玛雅二十进制计数法，属于数学符号，可以自由绘制），竖向三行，分别标注：**穿越次数 / 累计年代 / 距上次校准**。
数字随拍递增：穿越次数在每一拍 +1（从 19 数到 31，最后一位在过框时进位成 32 —— 用点横表示）。
更妙的一笔：抄写员正在给第三行补数字，补到页边时发现**格子不够了**，把最后两个点**挤到了红色框线外面**，还画了一个小小的箭头指向框外。
强拍上：抄写员的笔尖点一下（一个小墨点闪现），被挤出去的那两个点亮一下。

## 强拍动作
- 第 1 拍：数字栏最后一位 +1（点横重排）。
- 第 3 拍：字格阶跃移动 + 轻微旋转回正。
- 第 5 拍：神祇形象的包裹抖一下（里面的东西顶出来一块）。
- 过框：红色框线整体加深一次，像重新描了一遍。

## 禁止项
- 不写真实玛雅象形文字（那些是有具体读音的字），只用自创的抽象符号填满字格。
- 点横数字只用于**计数**，不组合成任何真实历法日期（如长纪历日期）。
- 神祇形象必须自创抽象，不复制任何真实玛雅神祇的可辨识造型。
- 无《神秘博士》相关视觉。
