# 15 示波器（Oscilloscope / 1950s）

- **index** 14 ｜ 全片时间窗 89.0–95.0s ｜ 文件 `src/scenes/s15-oscilloscope.js`
- **画风锚点**：1950s 实验室示波器的**矢量显示**——圆形绿色荧光屏、黑底、发光线条、余辉拖尾、扫描抖动、电子管嗡鸣的视觉化（画面轻微呼吸）。参照"示波器"这一通用仪器形态，不复制任何真实品牌型号。

## 构图
- **圆形 CRT 屏**：圆心 `(500, 470)`，半径 `400`，占据画面主部。屏内底色近黑（#050805），屏内叠一层极淡的同心圆刻度网格（每 80 单位一圈，alpha 0.06）+ 十字中线（alpha 0.08）。
- 屏外是**仪器面板**：深色（#2a2a26）的金属面，带细密的横向拉丝纹理（固定种子）。
- 面板右下区域 `x 620..980, y 800..960`：三个**旋钮**（同心圆 + 一道指示白线 + 外圈刻度点）+ 两个拨杆开关。旋钮的指示线角度各不相同（手排固定值）；其中右起第一个是"被转错的那只"（见梗）。
- 面板左上 `x 40..260, y 40..110`：一块自撰的铭牌（**只写通用字样**，如 `MODEL TC-7` / `TIME BASE`，不出现任何真实厂商名）。
- **公路**会盖在 `y 770..940` —— 这一带正好是面板下沿，画成面板的阴影与一排散热孔。

## 笔法（本格的命脉）
- 一切由**发光线条**构成。发光的画法（不要用 `ctx.filter`）：
  ```js
  // 三层递减 alpha 的同形描边 + 一条亮芯
  for (let i = 3; i >= 1; i--) { stroke(51,255,102, 30*i); strokeWeight(w + i*2.2); drawPath(); }
  stroke(200,255,220, 240); strokeWeight(1.4); drawPath();     // 亮芯
  ```
- **余辉拖尾**：同一图形向下偏移 4/8/12 单位再画三遍，alpha 依次 0.35/0.2/0.1（读作荧光余辉）。
- **扫描抖动**：整体 x 方向 ±2.2 单位的**10fps 阶跃**抖动：`Math.floor(local*10)` 取种子。
- **扫描亮点**：一条横向的亮线每 0.25 秒从屏顶扫到屏底（周期 0.5 秒扫两轮）。
- 屏面玻璃感：一道从左上到右下的极淡斜向反光（alpha 0.05）。

## 时空舱处理
用 `drawVehicle` 覆盖：
- 舱体**由发光线条构成**：只画轮廓——方形舱身、四坡短檐（折线）、3×2 六个窗格的框线、六角灯笼的六边形、刻度盘的圆 + 12 道刻度 + 指针、宽底座的线。内部全空（露出屏底黑）。
- 灯笼位置的**时间漩涡**是一个小的**李萨如图形**（`x = sin(3θ), y = sin(2θ+δ)`，θ 随 `swirlAngle(t)` 走），δ 缓慢变化。
- 全部带余辉拖尾 + 扫描抖动（与其他图形一致）。
- 注意：**不要画驾驶员剪影**（这格是矢量图形，不是画）。

## 梗（第 2 小节）
一只**线条画的简笔手**从画面右下角伸进来（只用 7~9 条线勾出手的轮廓 + 两根手指捏着旋钮），拧了一下右边第一只旋钮。
- **瞬间**：舱体的所有线条"崩"成一团**李萨如图形**——原本的方形轮廓消失，变成一条连续的正弦参数曲线（`x = cx + A·sin(5θ+δ), y = cy + B·sin(4θ)`），充满整个屏，持续约 1 拍（0.5 秒），期间 δ 快速变化、辉光变强（过载）。
- **下一拍**：手松开旋钮（手指抬起），曲线"啪"地弹回舱体原形（用 0.12 秒的阻尼过渡，加一次全屏亮度闪白 8%）。
- 手在梗结束后（local 4.5 之后）收回画面外。

## 无缝衔接（必做）
第 14 格结尾（local 6.0）已经是"全绿线描 + 余辉 + 扫描抖动"的状态，本格开头必须接得住：
- `local 0.0 ~ 0.6`：延续第 14 格结尾的观感（全绿、抖动幅度最大 3.5 单位、扫描亮线密集）。
- `local 0.6 ~ 1.2`：抖动幅度衰减到 2.2，屏内的同心圆刻度网格与面板**淡入**（读作"镜头拉远，露出这台仪器"）。

## 强拍动作
- 第 1 拍：扫描亮线扫到底部（周期为 0.5 秒，与拍同步）。
- 第 3 拍：李萨如的频率比跳档（3:2 → 5:4 → 7:5 → 回到 3:2）。
- 第 5 拍：屏面亮度轻微过载闪一下（+8%，衰减 0.2 秒）。
- 过框：全屏绿色亮一次（读作"过框推近"）。
