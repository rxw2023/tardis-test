# 09 八大山人写意（Bada Shanren / 约1690）

- **index** 8 ｜ 全片时间窗 53.0–59.0s ｜ 文件 `src/scenes/s09-bada.js`
- **画风锚点**：清初大写意的极简一路——寥寥数笔、奇崛造型、翻白眼、涩笔、**极端留白**。只取"大写意"这一公有领域笔法概念，不临摹任何具体作品，不署名。

## 构图
- 纸底满铺（`paper(g, { base:[236,231,219], fiber: 1.4, mottle: 0.7 })`），**85% 画面是空白**。
- 内容只有四处：
  - 中间偏上 `x 380..560, y 300..520`：**翻白眼的方盒子**（舱体）。
  - 左下方 `x 180..330, y 560..660`：一小丛墨（三笔兰草或一块破石，选一个，不要两个）。
  - 右下角 `x 700..800, y 600..660`：一条更小的**翻白眼鱼**。
  - 右上角 `x 840..900, y 90..140`：一枚朱红印章（自刻抽象字，不写"八大山人"）。
- 除此之外**什么都没有**。留白必须是真的空。

## 笔法
- 全部用 `inkStroke` / `dryLine`，笔画**涩**：`dry: 0.42~0.62`，`taper: 0.6~0.85`，`weight: 5~14`（大写意是大笔，不是小笔）。
- **一笔成形**，不叠加、不修改、不排皴。全格总笔数控制在 **25 笔以内**。
- 墨色：一笔之内有浓淡（起笔浓、行笔淡、收笔飞白），用 `inkStroke` 的 dry 与多次不同 alpha 叠加实现（同一路径画 1~2 遍即可，不要 3 遍以上）。
- 边缘：笔画末端留**断锋**（笔离开纸的飞白尾巴）。

## 调色
```
纸 #ece7db   墨 #22201d（浓）/ rgba(34,32,29,0.45)（淡）   朱印 #9a3a2a
```
全幅只有纸、墨、一枚朱印。

## 时空舱处理
用 `drawVehicle` 覆盖，**这是本格的核心**——舱体被画成一只**翻白眼的方盒子**，总共只用 6~8 笔：
1. 一笔方形的框（起笔重、收笔飞白）—— 舱体轮廓，略微歪斜、上宽下窄（奇崛）。
2. 框内**两块留白** = 两只**眼白**（实际是纸色，用两条弧线围出形状）。
3. 两只眼白里各点一个**偏心的小黑眼珠**（靠上翻，直径 12，位置在上缘，这就是"翻白眼"）。
4. 头顶一笔短竖 + 一个小圆 = 六角灯笼（画成一根呆毛挑着一个点）。
5. 底部一撇（鱼尾状的一笔，收笔飞白）= 宽底座。
整体是"一只方形的、翻着白眼的生物"，同时还能读出是那个舱体的骨架。
- 移动：x 随 `routeU` 走，y = 890 + hoverY。悬浮起伏在这样简的形上要**更慢更慵懒**（把 hoverY 乘 0.6）。

## 梗（第 2 小节）
它孤零零站在大片留白里。右下角那条更小的翻白眼鱼也翻着白眼**看着它**。两个白眼互相瞪着，谁也不动。
强拍上：鱼尾摆一下（一笔重画，幅度很小）；方盒子的眼珠（小黑点）在强拍上**抖一下**（位移 2 单位然后弹回，不是转动——就是不屑地抖）。
画面最下方（被公路压住的位置之上）可以有一行极小的竖排自撰小字，例如"翻白眼者，非鱼也"—— 字体极小（textSize 16）、淡墨、竖排放在最右侧空白处。**不要出现任何与《神秘博士》相关的字样**。

## 强拍动作
- 第 1 拍：鱼尾一摆（重画一笔，衰减）。
- 第 3 拍：眼珠抖一下（2 单位位移 + 弹回）。
- 第 5 拍：左下的兰草/石头轻微晃动（整个形做一个 0.5 度的旋转再回正）。
- 过框：全幅墨色统一加深 12% 再收回（读作"镜头推近"）。

## 禁止项
- **不临摹八大山人任何具体作品的构图**（不画他标志性的具体鱼/鸟形态，翻白眼鱼为自绘的极简形）。
- **不署名、不写"八大山人"、不写"朱耷"**；印章内是自创的抽象符号。
- 全格笔数 ≤ 25，留白 ≥ 80%。宁可少画，不可多画。
- 无《神秘博士》相关视觉。
