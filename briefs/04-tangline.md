# 04 唐代白描（Tang Line Drawing / 约750）

- **index** 3 ｜ 全片时间窗 23.0–29.0s ｜ 文件 `src/scenes/s04-tangline.js`
- **画风锚点**："吴带当风"——唐代白画，纯墨线、不施色、不皴不染，靠线条的连绵与方向造势。参照仅限这一公有领域笔法概念。

## 构图
- 纸底满铺（#efe6d3），**大片留白**：主体只占画面左下到右中的一条对角带，其余 60% 是空白纸。
- 舱体在 `x 260..520` 一带（第 1 小节偏左，第 3 小节偏右），贴地 y 890，尺寸 1.0。
- 从舱体尾部向右上方拉出**三条主飘带**，横贯整幅到 `x 980`，另有两条短飘带向下垂。
- 点缀：右下角一株小树（纯线描，枝被飘带卷住）、左上角一枚朱红印章（`seal`）、右上空白处两行竖排小字（自撰，例如"风起于青萍之末"级别的中性句子，**不要出现塔迪斯/神秘博士字样**）。

## 笔法
- **纯线，无面**。全程只用 `inkStroke`（少量 `dryLine` 做飞白），不填任何色块。
- 线宽 1.4~4.2，粗细随线条走向缓慢变化（起笔略重、行笔均匀、收笔尖）——用 `taper: 0.35~0.55`。
- 飘带：每条由一条主线 + 两条伴线组成，三条线间距 6~14 单位，形成"带宽"；中段加 8%~14% 飞白。
- 舱体轮廓线：最细（1.2~2.0），读作"轻灵"；飘带最粗（3~4.2），读作"有风"。
- 纸面用 `paper(g, { base: [239,230,211], fiber: 1.2, mottle: 0.6 })`，纤维要明显。

## 调色
```
纸 #efe6d3   墨 #1c1a17（浓）   淡墨 rgba(28,26,23,0.35)   朱印 #b0342a
```
全幅只有纸色 + 墨色 + 一枚朱印三种颜色。

## 时空舱处理
用 `drawVehicle` 覆盖：
- 舱体被画成**纯线稿**：只勾外形——四坡短檐、3×2 横窗的框线、六角灯笼的六边、刻度盘的圆与十二道刻度、宽底座。内部全空（露出纸色），不填青瓷色。
- 线宽 1.2~2.0，`taper: 0.4`，`dry: 0.08`（一点点飞白）。
- 从灯笼顶部和舱体四角长出飘带（见梗）。
- 驾驶员：从中间上排窗探出，衣带当风（身体 + 两条向后飘的衣纹线），挥手时（wave=true）手臂线抬起来。

## 梗（第 2 小节）
三条主飘带**太长**，飞到画外时把右下角那株小树的整棵树冠卷进风里——树的枝干被拉向飘带的走向，树叶（一簇簇的短线）朝右飞散。
更妙的一笔：最上面那条飘带的末端，缠住了画面右上角那枚刚盖下的朱红印章的**系绳**，印章被拖得歪了一点（歪角随飘带相位轻微摆动）。
强拍上：三条飘带各推进一个波峰（一条长正弦，每拍推进 1/2 波长）。

## 强拍动作
- 第 1 拍：飘带波峰整体前移半个波长（连续可微，不要跳变）。
- 第 3 拍：树的枝干摆到极值，树叶飞散速度峰值。
- 第 5 拍：印章歪角回正再歪（阻尼摆动）。
- 过框：所有线宽统一加粗 0.6 再收回（读作"过框时镜头推近"的呼吸）。

## 禁止项
- 不描摹《八十七神仙卷》《送子天王图》等任何具体作品的构图与人物。
- 除一枚自刻朱印与两行中性自撰小字外，不出现任何文字招牌、品牌。
- 无《神秘博士》相关视觉。
