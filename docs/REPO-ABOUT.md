## 二、一段式（README 顶部 / 视频简介 / 转发语）

> 《塔迪斯测试》是一部 137 秒的代码动画短片。一辆原创时空舱沿一条贯穿全片的时间公路，依次穿过 20 个时代与画风——从撒哈拉岩画、汉画像石拓片、浮世绘，一路开到蒸汽波和 8-bit 像素游戏，每过一道画框就换一种画法。全片 8220 帧画面与 137 秒配乐没有任何素材：画面由 p5.js 在无头 Chrome 里逐帧算出，配乐由 Web Audio 现场合成（连混响都是现算的），再交给 ffmpeg 合成。它不是 AI 生成的视频，而是一段程序。

## 三、完整描述（仓库首页长描述 / 项目介绍页）

《塔迪斯测试》是一部 137 秒、120 BPM 的代码动画短片，共 20 个版块。它的核心设定很简单：全片只有一条公路、一辆时空舱、一条主旋律。

时间轴上，每个版块固定占 3 小节 6 秒——第 1 小节进场，第 2 小节高光（驾驶员挥手、一个必须一眼看懂的梗），第 3 小节驶出画框。全片 60 小节，过框正好落在强拍上，21 次过框音构成整片的节奏锚点。

画面上，每个版块在 1000×1000 的单位空间里作画，映射到 1920×1080 中央的 1080 正方形，左右各 420px 边区留给公路延伸与标题卡。公路、画框、舱体由主调度统一绘制，场景只负责"地面以上"，于是同一辆舱体在岩画里是粗线条、在拓片里是白线黑影、在浮世绘里是平涂色块、在像素版块里是一枚瓦片精灵。

音乐上，全片只有一条 12 小节的主旋律（A 小调骨架），20 个版块各取 3 小节循环 5 次走完。每个版块只决定"用什么乐器、什么音阶"演奏它——旋律以相对主音的半音数存储，再按各时代音阶就近吸附，所以轮廓始终是同一条，听感却一路在换。

技术上，它刻意不用 Remotion、Three.js 或任何视频框架：每帧被压缩成一个纯函数 `renderFrame(g, t)`，Puppeteer 驱动无头 Chrome 逐帧调用、截图，12 段并行；音频在 `OfflineAudioContext` 里离线渲染后手写 WAV 头导出。整条链路唯一的 npm 运行时依赖是 `puppeteer-core`，其余全部手写。

所有版块只致敬已进入公有领域的风格与作品，不复刻可辨认的具体构图，不出现真实品牌与界面；时空舱为原创设计，与任何现有 IP 无关。
